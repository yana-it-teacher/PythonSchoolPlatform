# 🐍 «Пітоніка» — Навчальна платформа основ програмування Python для школярів

Сучасний інтерактивний веб-застосунок для вивчення основ алгоритмізації, мови Python та графічного модуля Turtle учнями середньої школи.

---

## 🌟 Головні можливості платформи

1. **Збереження профілю та імені учня**:
   - Автоматичне збереження в браузері (`localStorage`) імені учня, класу, обраного аватара/маскота.
   - Підтримка індивідуального прогресу на шкільному комп'ютері.
   - Можливість редагування профілю в один клік.

2. **Відстеження прогресу виконаних завдань**:
   - Повний контроль прогресу за кожним із **25 уроків**.
   - Індикатори статусу: `▶️ Розпочати`, `⏳ В процесі`, `✅ Виконано (+XP)`.
   - Загальний відсоток проходження курсу та окремий прогрес за кожним із 5 тематичних блоків.
   - Автозбереження робочих чернеток коду учня для кожного завдання.

3. **Робоча панель учня (Student IDE & Learning Workspace)**:
   - **Бічна панель**:
     - 📖 **Теорія та завдання**: доступне пояснення концепцій з прикладами коду.
     - 💡 **Багаторівневі підказки**: 3 рівні допомоги (Ідея ➔ Необхідні команди ➔ Зразок рішення).
     - 🏁 **Очікуваний результат**: візуальний та текстовий орієнтир, що має вивести або намалювати програма.
   - **Інтерактивний редактор Python**:
     - Підтримка клавіші `Tab`, авто-відступів у 4 пробіли, нумерація рядків.
     - Кнопка **«▶️ Запустити код»** для миттєвого виконання в браузері.
     - Кнопка **«✅ Перевірити розв'язок»** з автоматичною оцінкою правильності та нарахуванням XP.
   - **Двоканальне виведення**:
     - 🐢 **Полотно Turtle Canvas**: малювання ліній, фігур, кіл, заливка кольором, перемикання координатної сітки `(x, y)` та регулятор швидкості!
     - 💻 **Консольний термінал**: підтримка `print()` та інтерактивного введення `input()` з красивими діалогами.

4. **Система мотивації та гейміфікації**:
   - **Досвід (XP)** за кожне виконане завдання та бліц-раунди.
   - **10 рівнів майстерності** (від «Юного дослідника» до «Легенди Кодингу»).
   - **12 унікальних бейджів/досягнень** (наприклад: *«Перша команда»*, *«Олімпійський рекорд»*, *«Володар циклів»* тощо).
   - **Звукові ефекти** через Web Audio API (фанфари нового рівня, мажорний переможний акорд, приємні кліки — працює без завантаження зовнішніх mp3!).
   - **Анімоване святкове конфеті** на полотні при успішному виконанні завдань!

5. **Інтерактивний тренажер синтаксису команд (4 режими)**:
   - 🧩 **Конструктор коду**: складання правильних команд Python з перемішаних блоків/токенів.
   - 🔍 **Знайди помилку**: вибір коректного синтаксису серед типових учнівських помилок.
   - ✏️ **Встав пропущене**: інтерактивне заповнення ключових слів (`input`, `for`, `penup` тощо).
   - ⏱️ **Спідран Бліц (60 секунд)**: швидкісне закріплення синтаксису з комбо-множником та таблицею рекордів.

6. **Адмін-доступ для вчителя**:
   - Вхід за паролем (за замовчуванням: `teacher123` або `вчитель`, з можливістю зміни).
   - **Керування завданнями**: додавання нових завдань, редагування існуючих (теорія, код, підказки, XP, очікуваний результат), видалення або скидання курсу до початкових 25 уроків.
   - **Журнал успішності класу**: список учнів, відсоток пройденого матеріалу, кількість виконаних робіт та отриманих досягнень.
   - **Експорт даних**: збереження журналу в Excel (CSV) та резервне копіювання навчального плану в JSON.

## 📚 Структура навчального курсу (25 уроків)

### Блок 1. Алгоритми та перші кроки (Уроки 1-5)
* **Урок 1**: Поняття алгоритму. Виконавці та їхні системи команд.
* **Урок 2**: Способи опису алгоритмів (блок-схеми, слідування, розгалуження, повторення).
* **Урок 3**: Програмне середовище Python. Перша програма. Команда `print()`.
* **Урок 4**: Виведення текстових повідомлень. Знайомство з лапками. Форматований вивід.
* **Урок 5**: Знайомство з turtle. Команди руху та повороти. Малювання геометричних фігур.

### Блок 2. Лінійні алгоритми: Дані та обчислення (Уроки 6-10)
* **Урок 6**: Поняття змінної. Типи даних (`int`, `float`, `str`). Вказівка присвоєння.
* **Урок 7**: Математичні операції в Python (`+`, `-`, `*`, `/`, `%`, `//`). Об'єднання (+) та дублювання (*) рядків.
* **Урок 8**: Лінійні алгоритми. Введення даних з клавіатури `input()`. Перетворення типів `int()`, `float()`.
* **Урок 9**: Пріоритет операцій та дужки в обчисленнях.
* **Урок 10**: Практична робота: Створення калькулятора за блок-схемою.

### Блок 3. Графічні можливості Turtle (Уроки 11-15)
* **Урок 11**: Малювання фігур з введеними розмірами. Команда `write()`.
* **Урок 12**: Кольорова палітра. Команди `pencolor`, `fillcolor`, `begin_fill`, `end_fill`, `width`.
* **Урок 13**: Координатна площина. Команда `goto(x, y)`, `penup()`, `pendown()`.
* **Урок 14**: Графічний малюнок за координатами.
* **Урок 15**: Практична робота: Малювання олімпійських кілець.

### Блок 4. Алгоритми з розгалуженнями (Уроки 16-20)
* **Урок 16**: Висловлювання. Логічний тип даних. Операції порівняння (`>`, `<`, `==`, `!=`).
* **Урок 17**: Складені умови. Оператори `and`, `or`, `not`.
* **Урок 18**: Неповне розгалуження. Конструкція `if`. Відступи у Python.
* **Урок 19**: Повне розгалуження. Конструкція `if-else`.
* **Урок 20**: Практична робота: «Розумна Черепашка».

### Блок 5. Алгоритми з повторенням (Уроки 21-25)
* **Урок 21**: Поняття циклу. Цикл з лічильником. Команда `for` та функція `range()`.
* **Урок 22**: Зоряне небо за допомогою команди `for`. Випадкові числа `randint`.
* **Урок 23**: Малювання правильних багатокутників (трикутник, квадрат, шестикутник).
* **Урок 24**: Математичні візерунки: спіралі та «квіти».
* **Урок 25**: Практична робота: Програма для перевірки знання таблиці множення.

## 🚀 Як запустити платформу

### Варіант 1: Запуск через локальний сервер Python (Рекомендовано)
1. Двічі клікніть по файлу `start.bat` (у Windows).
2. Або у терміналі виконайте:
   ```bash
   python server.py
   ```
3. Браузер автоматично відкриє платформу за адресою: `http://localhost:8000`.

### Варіант 2: Пряме відкриття у браузері
* Просто відкрийте файл `index.html` у будь-якому сучасному веб-браузері (Chrome, Edge, Firefox, Safari). Всі функції працюють на 100% автономно без інтернету та сторонніх бібліотек!
