# 🐍 «Пітоніка» — Навчальна платформа основ програмування Python для школярів

Сучасний інтерактивний веб-застосунок для вивчення мови Python та графічного модуля Turtle учнями середньої школи (5 та 6 класи).

---

## 🌟 Навчальні курси платформи

### 🐢 Курс 1: «Основи Python та Turtle: 5 клас» (25 уроків)
* **Блок 1. Алгоритми та перші кроки (Уроки 1–5):** Поняття алгоритму, СКИ, блок-схеми, перша програма, команда `print()`, лапки та знайомство з `turtle`.
* **Блок 2. Лінійні алгоритми: Дані та обчислення (Уроки 6–10):** Змінні, типи (`int`, `float`, `str`), операції `//`, `%`, конкатенація/дублювання, введення `input()`, пріоритети, практична робота «Калькулятор».
* **Блок 3. Графічні можливості Turtle (Уроки 11–15):** Введення розмірів, `write()`, палітра (`fillcolor`, `begin_fill`, `end_fill`), координатна площина `goto()`, практична робота «Олімпійські кільця».
* **Блок 4. Алгоритми з розгалуженнями (Уроки 16–20):** Тип `bool`, порівняння, `and/or/not`, конструкція `if`, відступи, `if-else`, практична «Розумна Черепашка».
* **Блок 5. Алгоритми з повторенням (Уроки 21–25):** Цикл `for`, `range()`, зоряне небо з `randint`, правильні багатокутники, математичні спіралі, практична «Тренажер таблиці множення».

---

### 🛸 Курс 2: «Код Пригод: Python 6 клас» (19 уроків у 4 епізодах)
* **Епізод 1: «Штучний інтелект для кібер-дрона» (Розгалуження) (Уроки 1–6):**
  - Урок 1: Активація сенсорів: Базове розгалуження (if / else)
  - Урок 2: Навігація в тумані: Складні сенсори (and, or, not)
  - Урок 3: Підземний бункер: Вкладені умови (if всередині if)
  - Урок 4: Торговець артефактами: Калькулятор із пільгами
  - Урок 5: Сортувальний капелюх: Множинний вибір (elif)
  - Урок 6: Практична робота: Текстовий квест «Втеча з космічної станції»
* **Епізод 2: «Автоматизація бази» (Цикл з параметром) (Уроки 7–9):**
  - Урок 7: Захисний паркан бази: Цикл for та range(start, stop, step)
  - Урок 8: Генератор досвіду (XP): Лічильник у циклі
  - Урок 9: Скарбничка дракона: Накопичення суми (s += a)
* **Епізод 3: «Нескінченна петля часу» (Цикл з умовою while) (Уроки 10–15):**
  - Урок 10: Гра «Вгадай код від сейфа»: Цикл while
  - Урок 11: Радар енергії: Зворотний відлік
  - Урок 12: Сканер корисних копалин: if всередині for
  - Урок 13: Дрон на арені: Розумний Turtle, що відбивається від стін
  - Урок 14: Вибір зброї: Цикл усередині розгалуження
  - Урок 15: Генератор ігрового інвентарю: Захист від введення некоректних даних
* **Епізод 4: «Архітектор матриці» (Вкладені цикли та пошук) (Уроки 16–19):**
  - Урок 16: Піксель-арт та таблиця рекордів: Вкладені цикли
  - Урок 17: Створення ігрової карти в Turtle (тайлові блоки)
  - Урок 18: Злам шифру агента: Задачі повного перебору (Brute Force)
  - Урок 19: Практична робота: Фінальна гра «Космічна лотерея / Тренажер реакції»

## 🚀 Функціонал платформи

1. **Миттєве перемикання курсів:**
   - Швидкий перемикач курсів у верхній шапці (`🐢 5 Клас` ⇄ `🛸 6 Клас`).
   - Інтерактивна карта на сторінці Roadmap з окремим підрахунком прогресу для кожного курсу.

2. **Оновлений інтерпретатор Python (в браузері):**
   - Підтримка циклів `while` із захистом від зависання браузера (ліміт до 5000 ітерацій).
   - Підтримка переривання `break` та переходу `continue`.
   - Повноцінний ланцюжок `if - elif - elif ... - else:`.
   - Вкладені умови та вкладені цикли (подвійні відступи).
   - Скорочені оператори накопичення `+=`, `-=`, `*=`, `/=`.
   - Інтерактивне введення `input()`, консоль `print()`, малювання на Canvas `turtle`.

3. **Сюжетні місії та робоча панель учня:**
   - Бічна панель з описом фантастичного сюжету місії (для завдань 6 класу).
   - Багаторівневі підказки (Ідея ➔ Команди ➔ Зразок розв'язку).
   - Очікуваний результат та автоперевірка з нарахуванням XP.

4. **Тренажер синтаксису (з підтримкою 6 класу):**
   - Конструктор коду (включаючи `while`, `elif`, `+=`).
   - Пошук помилок (синтаксис while, розгалуження elif).
   - Встав пропущене та 60-секундний спідран-бліц.

5. **Кабінет вчителя:**
   - Пароль за замовчуванням: `teacher123` або `вчитель`.
   - Фільтр завдань за класами (5 клас / 6 клас / усі 44 уроки).
   - Створення нових завдань із зазначенням курсу та блоку/епізоду.
   - Експорт журналу учнів у Excel (CSV) та резервне копіювання в JSON.

---

## 🛠️ Як запустити

1. Подвійний клік на `start.bat` (Windows).
2. Або через термінал: `python server.py`.
3. Або просто відкрийте `index.html` у браузері.
